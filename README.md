# Neon Assault — اپ اندروید

## ساخت APK با گیت‌هاب (بدون نصب هیچ چیزی روی کامپیوتر)

1. در github.com یک مخزن (Repository) جدید بسازید.
2. همه‌ی فایل‌های این پوشه را در آن آپلود کنید (Add file ← Upload files).
   - پوشه‌ی `.github` مخفی است و گاهی هنگام درگ‌کردن آپلود نمی‌شود. حتماً مطمئن شوید فایل
     `.github/workflows/build-apk.yml` در مخزن هست. اگر نبود: Add file ← Create new file،
     در کادر نام همین مسیر را تایپ کنید و محتوای `build-apk.yml` را داخلش بچسبانید.
3. به تب **Actions** بروید. ساخت خودکار شروع می‌شود (حدود ۵ تا ۱۰ دقیقه). اگر شروع نشد،
   «Build Android APK» را انتخاب کنید و **Run workflow** بزنید.
4. وقتی تیک سبز شد، روی همان اجرا کلیک کنید و از بخش **Artifacts** فایل
   `neon-assault-apk` را دانلود کنید. داخل آن `app-debug.apk` است.
5. فایل را روی گوشی ببرید و نصب کنید (اجازه‌ی «نصب از منابع ناشناس» را بدهید).

## نکته‌ها
- این APK از نوع debug است و برای نصب مستقیم کافی است. برای انتشار در گوگل‌پلی یا بازار
  به نسخه‌ی release با امضای دیجیتال نیاز دارید.
- اپ فقط افقی و تمام‌صفحه است. دکمه‌ی خروج منو برنامه را می‌بندد و دکمه‌ی Back گوشی کار می‌کند.
- آیکون برنامه از `assets/icon-only.png` ساخته می‌شود. با جایگزین‌کردن آن (۱۰۲۴×۱۰۲۴) آیکون عوض می‌شود.
- بازی در `www/index.html` است. هر تغییری در آن بدهید و دوباره آپلود کنید، APK جدید ساخته می‌شود.
- نام برنامه و شناسه‌ی بسته در `capacitor.config.json` است.
